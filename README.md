# Capstone_Project_Kaggle
This Python program demonstrates a simulated AI-driven sequential agent that monitors a Jenkins pipeline's Fortify scan stage and verifies approval status in Fortify SSC when necessary. Since neither Jenkins nor Fortify is available, the solution uses two mock systems—MockJenkins and MockFortifySSC—to realistically imitate pipeline scan durations and SSC project states. The agent first checks the scan duration of each service; if the scan exceeds a defined threshold (15 minutes), it assumes the pipeline may be blocked and then queries the corresponding project's status in the simulated SSC system. If the SSC status is found to be “Pending Approval,” the agent logs the service along with its scan duration, approval state, and timestamp. All logged entries are compiled into a structured pandas DataFrame, producing a final report of services that need attention. This simulation effectively showcases how an autonomous DevSecOps monitoring agent would operate in a real CI/CD environment, making it ideal for demonstration, learning, or prototyping before integrating with actual Jenkins and Fortify SSC APIs.
